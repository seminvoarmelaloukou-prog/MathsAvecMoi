Bienvenue dans l’espace enseignant Campus Flex.

Compte administrateur connecté :
Suivi des apprenants La base contient les profils, classes, numéros vérifiés et données de progression des apprenants.
Résultats et classement Le tableau des résultats, des points et du classement sera ajouté après la sécurisation du rôle administrateur Firebase.
Passage de classe Le changement de classe d’un apprenant sera possible depuis cet espace une fois les droits administrateur activés côté serveur.
Messages WhatsApp Les numéros WhatsApp vérifiés pourront être utilisés pour contacter les apprenants depuis un tableau sécurisé.
Cette page contrôle l’affichage avec ton e-mail Firebase. Elle ne donne pas encore les droits de lecture globale sur les profils élèves : ces droits seront ajoutés de manière sécurisée avec Firebase Admin SDK et un rôle administrateur.
